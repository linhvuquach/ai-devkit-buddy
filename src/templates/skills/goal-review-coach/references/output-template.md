# Review Output Template

Use this structure for a full written review (the person asked for a review, pasted a goal
document, or you're producing a shareable artifact). For a quick in-conversation check, compress
to: strength + top gap + one question, and offer the full template if they want it — don't force
the whole structure into every reply.

```markdown
## Executive Summary
[2-3 sentences: what the goal is trying to achieve, the overall verdict, and the single
highest-leverage change. Written for someone skimming, not reading the full review.]

## Overall Score: X.X / 5.0 — [Excellent | Solid | Workable | Needs Rework]
Confidence: [High | Medium | Low] — [one line on what, if anything, limited confidence]

## Dimension Scores
| Dimension | Score | Note |
|---|---|---|
| Clarity & Specificity | X/5 | |
| Outcome Orientation | X/5 | |
| Measurability | X/5 | |
| Achievability | X/5 | |
| Business Impact | X/5 | |
| Alignment | X/5 | |
| Ownership | X/5 | |
| Time-Bound | X/5 | |
| Scope Discipline | X/5 | |
| Dependencies | X/5 | |
| Risk Awareness | X/5 | |
| Psychological Ownership | X/5 | |

## Strengths
- [What's genuinely working — specific, not generic praise]

## Weaknesses
- [Highest-priority gaps first, tied to rubric dimensions]

## Risk Assessment
- [What could cause this goal to be missed or disputed at review time]

## Questions to Clarify
- [Only what you actually need answered to finish the review — not a padding list]

## Recommended Rewrite
> [The goal, rewritten per the rewrite rules. Mark any unconfirmed numbers as
> `[placeholder — confirm]` rather than inventing them.]

## Stretch Version
> [A more ambitious variant — only offer this if resource slack and safety checks in SKILL.md
> are actually met; otherwise state why you're not offering one.]

## Minimal / Conservative Version
> [A safer, more certain variant — useful if the person is already stretched thin elsewhere]

## Key Improvements
1. [Ranked, tied back to the priority-improvement dimensions from the rubric]

## Next Coaching Step
[One concrete action: what the person will confirm, decide, or check in on, and by when —
not just "use the rewritten version."]
```

## Compression rules

- **Quick check** ("is this goal good?", one goal pasted inline in chat): strength, top gap,
  one clarifying question or the rewrite if it's a simple fix. Skip the table.
- **Full review** (explicit ask, multiple goals, or a document): use the full template above.
- **Batch review** (a list of goals, e.g. a whole team's): use the full template per goal, but
  lead with a short cross-goal summary (common patterns you saw across all of them) before the
  per-goal breakdowns — that's often more useful than re-stating the same gap N times.
